Environment Variable

The Groq API key is stored securely in Netlify and is never exposed in frontend code or committed to GitHub.

GROQ_API_KEY=your_groq_api_key_here

The Netlify Function accesses the key through:

process.env.GROQ_API_KEY

Security

The actual Groq API key is not stored in the repository.

Only the environment variable name is referenced by the application:

process.env.GROQ_API_KEY

The production secret is managed through Netlify Environment Variables.
